## 🚀 Features

- 📰 Browse latest news articles
- 🔍 Search and filter by category or keyword
- 👥 User authentication (register/login/logout)
- 💬 Comment on articles
- ❤️ Like/save articles to favorites
- ⚙️ Admin dashboard (optional)

## 🛠️ Tech Stack

**Frontend**
- React (Vite)
- Tailwind CSS
- React Router

**Backend**
- Node.js
- Express
- MongoDB (Mongoose)
- JWT for auth
- Redis (optional for caching)
